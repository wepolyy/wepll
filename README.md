# Численные методы

Репозиторий с домашними заданиями по численным методам.

## Реализованные методы

### 1. Метод бисекции (деления отрезка пополам)

Программа на Python для приближённого нахождения корня нелинейного уравнения.

- Исследуемая функция: $f(x) = x^3 - x - 2$
- Отрезок: $[1; 2]$
- Точность: $\varepsilon = 0{,}0001$
- Файл: `bisection.py`

### 2. Метод простых итераций

Программа на Java для решения трансцендентного уравнения.

- Уравнение: $x - \cos x = 0$
- Отрезок: $[0; 1]$
- Точность: $\varepsilon = 10^{-4}$
- Файл: `SimpleIteration.java`

#### Идея метода

Уравнение $f(x) = 0$ приводится к эквивалентному виду:

$$x = \varphi(x)$$

Решение находится последовательными приближениями:

$$x_{n+1} = \varphi(x_n), \quad n = 0, 1, 2, \ldots$$

#### Условие сходимости

Метод сходится, если на отрезке $[a, b]$ выполняется:

$$|\varphi'(x)| \le q < 1$$

#### Алгоритм

1. Привести уравнение $f(x) = 0$ к виду $x = \varphi(x)$.
2. Проверить условие сходимости $|\varphi'(x)| < 1$.
3. Задать начальное приближение $x_0$ и точность $\varepsilon$.
4. Вычислять $x_{n+1} = \varphi(x_n)$.
5. Остановиться при $|x_{n+1} - x_n| < \varepsilon$.
6. Вывести корень $x^*$ и число итераций.

#### Результат

Корень уравнения: $x^* \approx 0{,}739478$, число итераций — 20.

#### Запуск

```bash
javac SimpleIteration.java
java SimpleIteration
```

Требуется JDK 8 или выше.
