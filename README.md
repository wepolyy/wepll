### 3. Метод Ньютона и метод Хорд

Программа на Java для нахождения приближённого корня нелинейного уравнения.

* Исследуемая функция: \(f(x) = 2x - \frac{1}{\tan(x)}\)
* Отрезок: `[0; 1]`
* Точность: `ε = 0.0001`
* Файл: [NewtonAndSecant.java](NewtonAndSecant.java)

**Особенность:** В точке `x = 0` функция имеет разрыв (деление на ноль). Поэтому начальное приближение задается как `x0 = 0.7`.
