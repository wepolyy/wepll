# Метод бисекции (деления отрезка пополам)

## Описание программы

Программа реализует численный метод бисекции для приближённого нахождения корня
нелинейного уравнения вида **f(x) = 0**.

Исследуемая функция: **f(x) = x³ − x − 2**

Требуется найти корень уравнения **x³ − x − 2 = 0** на отрезке **[1; 2]**
с точностью **ε = 0,0001**.

Программа написана на языке **Python 3** и запускается из консоли. Она:

- задаёт границы отрезка `a` и `b`, а также точность `ε`;
- последовательно делит отрезок пополам, отбрасывая ту половину, где знак функции не меняется;
- останавливается, когда длина текущего отрезка становится меньше `2ε`;
- выводит найденное приближённое значение корня и значение функции в этой точке.

---

## Описание алгоритма

### Идея метода

Если непрерывная функция `f(x)` на концах отрезка `[a; b]` принимает значения
разных знаков, то внутри этого отрезка существует хотя бы один корень.
Деля отрезок пополам и выбирая ту половину, на концах которой функция снова
меняет знак, можно сколь угодно близко подойти к корню.

### Пошаговое описание

1. **Ввод данных.** Задать границы отрезка `a = 1`, `b = 2` и точность `ε = 0,0001`.
2. **Проверка условия сходимости.** Убедиться, что `f(a) · f(b) < 0`.
3. **Итерационный процесс.** Пока `(b − a) / 2 > ε` выполнять:
   1. Вычислить середину отрезка: `c = (a + b) / 2`.
   2. Если `f(a) · f(c) < 0`, то корень в левой половине: `b = c`.
   3. Иначе — корень в правой половине: `a = c`.
4. **Завершение.** Приближённый корень: `x ≈ (a + b) / 2`.
5. **Вывод результата.** Напечатать найденный корень и значение `f(x)`.

### Блок-схема (текстовая)

```

      │  Начало: a=1, b=2, ε │
      └──────────┬───────────┘
                 ▼
      ┌──────────────────────┐

      └──────────┬───────────┘
                 │ да
                 ▼
      ┌──────────────────────┐
      │  (b − a)/2 > ε ?     │──нет──┐
      └──────────┬───────────┘       │
                 │ да                │
                 ▼                   │
      ┌──────────────────────┐       │
      │  c = (a + b) / 2     │       │
      └──────────┬───────────┘       │
                 ▼                   │
      ┌──────────────────────┐       │

      └───┬──────────────┬───┘       │
       да │              │ нет       │
          ▼              ▼           │
      ┌───────┐      ┌───────┐       │

```

### Оценка сходимости

Метод бисекции сходится линейно: на каждой итерации длина отрезка уменьшается
вдвое. Количество итераций для достижения точности `ε`:

**n ≥ log₂((b − a) / ε)**

Для `b − a = 1` и `ε = 0,0001` требуется примерно **14 итераций**.

## Запуск

```bash
python3 bisection.py
```

Программа выведет все промежуточные итерации и итоговое приближённое значение корня.
